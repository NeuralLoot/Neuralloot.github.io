Last round, in real terms: Play a level to see the expert note here.

Word map: 💭 bubble = visible pre-answer text T · 🪙 gold bubble = final answer A · answer box = the visible response · ✋ STOP = an answer-only suppression instruction applied to the response · ✅ clean box = an empty-T response (counts toward ETR) · 💬 leaked bubble = visible explicit inference (counts toward EIR) · 🔋 brain power = a toy stand-in for the no-thinking–performance trade-off · 🔤 options = rewriting the question into a candidate-visible (multiple-choice) answer space.

The paper. Thinking Inertia: LLMs Keep Thinking When Told Not To (arXiv 2610.11765; project page). Each response is split into pre-answer text T and final answer A, then scored three ways: ETR (Empty-Thinking Rate, strict answer-only compliance), QRel. (question–pre-answer relevance, an instruction-aware embedding score) and EIR (Explicit Inference Rate, a blinded LLM judge deciding whether T contains an explicit inferential step). Accuracy is scored separately on A. Six models, six benchmarks (BoolQ, StrategyQA, MMLU, MMLU-Pro, GSM8K, MATH) and six intervention modes M1–M6 (Think-On, Think-Off, step-by-step CoT, Soft, Strict, Prefix forcing). Human explicit-inference labels agree with the GPT-5.5 judge 98.8% of the time (mean binary agreement).

What it found. (i) A no-think switch is not a no-thinking control: DeepSeek-V4-Flash (284B) keeps visible explicit inference in 99.9% of open-ended responses with thinking disabled. (ii) Thinking inertia: visible inference follows the answer space, Bool < MCQ < Open. Corpus EIR under Think-Off (M2) is 5.15% / 45.57% / 99.69%; under Strict answer-only prompting (M5) it is 0.12% / 25.39% / 62.00% (Table D.3, GPT-5.5 judge). (iii) On open-ended tasks, going from M2 to M5 raises mean ETR from near 0 to roughly 40% while mean accuracy drops by about 15 percentage points: the no-thinking–performance trade-off. (iv) Rewriting the same question so candidate answers are visible makes answer-only responses easier to produce.

How the game maps to it. Level 1 is the Boolean answer space (few, slow bubbles). Level 2 is open-ended: long bubble streams, and zapping past the 🔋 budget breaks the answer, so a clean box and a right answer pull against each other the way ETR and accuracy do in finding (iii). Level 3 adds the answer-space rewrite from finding (iv): a 🔤 option card turns an open question into A/B/C/D, which shrinks the stream and stops the 🔋 drain.

Deliberately simplified. The paper measures visible text only and makes no claim about hidden computation; neither does the game. Real suppression is a prompt or a thinking switch applied once to the whole response, not a per-token gate a person taps. A real response can also hold relevant non-inferential text, which EIR does not count; every leaked bubble here is treated as inference.
