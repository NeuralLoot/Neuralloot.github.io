What you just played. In DIB-Bench (Su, Xiang, Zhang, Zhang, UConn), a deployed AI agent is a stack of six parts: model + tokenizer, system prompt, tool specs + router, retrieval policy + docs, runtime dependencies, and a postprocessor that edits text after the model writes it. Each test tampers with exactly one part while keeping the answers the test suite checks correct. Output-only evaluators (a rule-based scorer, a Qwen3-8B LLM judge, a GPT-5-nano judge) only see answers, so they pass most tampered stacks. The identity channel compares a manifest hash (SHA-256 fingerprint) of each declared part with the deployed part. One read, zero sample answers, and it catches every one of the six tampers. In the game, the tag is the declared manifest, the scan is the observed one, and the three-shape code stands in for a hash.
