🔬 What's real

  • Real: the loop. An AI agent repeats think → call a tool → read what comes back (the observation) until it answers. That is the ReAct pattern (Yao et al. 2022).
  • Real: errors come back as text the agent has to read (τ-bench tools return strings like "Error: payment not found"). If it ignores them and repeats the same call, it loops. The ReAct paper shows an agent stuck repeating the same commands (Appendix D.2.2).
  • Real: step budgets. Agent runs get cut off: ReAct used 7 steps on HotpotQA and 5 on FEVER; τ-bench allows 30 actions per task.
  • Real: saying "done" too early. About 19% of GPT-4o's τ-bench failures were partly-finished requests.
  • Toy: the tools, tasks, answers, error odds (each level rolls which shop is closed and which tool times out), step counts and stars. Here you pick each tool; in a real agent the language model picks it from the same kind of clues.

Nerd notes

  • ReAct, ALFWorld (134 unseen games): best ReAct prompt 71% success vs best Act-only 45% (Table 3). HotpotQA error analysis: non-informative search = 23% of ReAct's error cases; repeating previous thoughts/actions is filed under reasoning errors (Table 2, Sec. 3.3).
  • τ-bench: gpt-4o function calling pass^1 ≈ 61.2% retail, 35.2% airline (Table 2); pass^8 < 25% in retail; failure breakdown Fig. 5 (partial resolution of compound requests ≈ 19%).
