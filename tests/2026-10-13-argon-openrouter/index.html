Can you turn off Gemini 4 Argon's thinking on OpenRouter?

A small test, run Oct 13 2026, after a public claim about Argon's thinking settings. We checked the settings ourselves and ran 40 hard math problems.

Setting enable_thinking=false does nothing on OpenRouter: Argon still averaged 127 thinking tokens per problem, the same as default (127).

Kid version: the "stop thinking" switch isn't wired up. The model keeps doing its scratch work anyway. The switch that does work is effort=minimal, which cut thinking to 10 tokens.

What this shows

  • You can't fully switch Argon's thinking off here: effort=none and reasoning.enabled=false are refused with an error.
  • enable_thinking=false is accepted but ignored. Its tokens and cost match the default run.
  • effort=minimal is the real "low thinking" switch: 10 thinking tokens on average vs 127, and it still got 40/40.
  • Gemini 3.8 Flash got 39/40 and was the cheapest overall.

Limits

  • N=40 problems. One problem is 2.5 points.
  • The test is too easy to rank these models: three setups scored 40/40.
  • One run each, temperature 0. No repeats, so no error bars.
  • Settings test used a single prompt per setting.

🤓 Nerd notes

Method. GSM8K test, 40 items: random.Random(20261013).sample of the 200 items with most gold calc steps. Gold steps counted as <<calc>> annotations in the answer. Prompt asks for a final ANSWER: n line; numeric match. temperature 0, seed 20261013, max_tokens 16000, via openrouter.ai/api/v1/chat/completions. All 160 calls returned answers with no errors.

Models. google/gemini-4-argon ($2 / $10 per million input / output tokens) and google/gemini-3.8-flash ($0.75 / $3.75), from the public /api/v1/models list on Oct 13 2026. Costs are OpenRouter's reported per-call cost.

Total spend. $0.49 for the eval.
